## 1. 这是什么

「阈牌」是一个**中文塔罗反思工具**，不是算命软件。

它帮你把模糊的感受变成可以看见、可以触摸的东西：
- 你输入一个问题
- 系统帮你澄清问题
- 抽一张或多张牌
- 牌面是可交互的——点击牌面上的符号，解释从牌面浮现
- 你可以写下感受，保存快照，以后回看

**它不预测未来，不替你做决定。** 它像一个安静的朋友，帮你把看不清的东西说出来。

## 2. 你需要准备什么

| 需要的东西 | 说明 | 在哪里获取 |
|-----------|------|-----------|
| **一台电脑** | Windows 或 Mac 都可以 | 你自己的电脑 |
| **Node.js** | 运行这个项目的工具 | [nodejs.org](https://nodejs.org) 下载 |
| **网络** | 下载东西需要联网 | 你自己的网络 |
| **（可选）AI API Key** | 让解读更智能 | DeepSeek 或 OpenAI 官网申请 |

### 安装 Node.js（如果还没装）

1. 打开浏览器，访问 **https://nodejs.org**
2. 点击左边那个绿色按钮「**LTS**」（推荐版本），下载
3. 双击下载的文件，一路点「下一步」安装
4. 安装完后，**重启你的电脑**（重要！）

> **Mac 用户：** 也可以打开「终端」，输入 `brew install node`（如果装了 Homebrew）。

## 3. 方式一：手动部署（推荐小白）

### 第一步：下载项目

#### 方法 A：用 Git 下载（推荐）

1. 打开「终端」（Mac）或「命令提示符 / PowerShell」（Windows）
2. 输入以下命令，按回车：

```bash
git clone https://github.com/xubo15384751795-sys/tarot-reflector.git
cd tarot-reflector
```

#### 方法 B：直接下载压缩包

1. 打开浏览器，访问 **https://github.com/xubo15384751795-sys/tarot-reflector**
2. 点击绿色的「**Code**」按钮
3. 点击「**Download ZIP**」
4. 下载完成后，解压到你喜欢的位置（比如桌面）
5. 打开「终端」或「命令提示符」，用 `cd` 命令进入解压后的文件夹：

```bash
cd ~/Desktop/tarot-reflector-main
```

### 第二步：安装依赖

在终端里输入：

```bash
npm install
```

按回车，等待（可能需要 1-3 分钟，取决于网速）。

> **看到很多文字在滚动是正常的，不用担心。**
> **如果出现红色错误，看下面的「常见问题」。**

### 第三步：启动项目

```bash
npm run dev
```

等待看到类似这样的文字：

```
  ▲ Next.js 16.x.x
  - Local:        http://localhost:3000
  ✓ Ready in xxxms
```

### 第四步：打开浏览器

1. 打开浏览器（Chrome / Edge / Safari 都可以）
2. 在地址栏输入：**http://localhost:3000**
3. 按回车

**你看到了「阈牌」的首页！** 🎉

### 第五步（可选）：配置 AI 解读

不配置也能用。想让解读更智能，看[第 5 节](#5-配置-ai-解读可选)。

## 4. 方式二：Agent 部署（用腾讯 CodeBuddy）

> **适合完全不想碰代码的用户。** 让 AI 帮你完成所有操作。

### 第一步：安装腾讯 CodeBuddy

1. 打开浏览器，访问 **https://codebuddy.tencent.com**
2. 点击「**下载安装**」
3. 安装完成后，重启你的代码编辑器（VS Code 或 Cursor）

> **CodeBuddy 是什么？** 它是腾讯出品的 AI 编程助手，可以帮你自动执行命令、写代码、部署项目。你只需要告诉它你想做什么，它帮你做。

### 第二步：打开 CodeBuddy

1. 打开 VS Code（或 Cursor）
2. 按 `Ctrl + Shift + P`（Mac 用 `Cmd + Shift + P`）
3. 输入 `CodeBuddy`，选择「**打开 CodeBuddy 面板**」

在 CodeBuddy 的对话框里，**复制粘贴**以下指令：

## 5. 配置 AI 解读（可选）

> **不配置也能用！** 系统内置本地模板引擎，不需要 AI 就能生成解读。
>
> 配置 AI 后，解读会更自然、更贴合你的问题。

### 方式 A：用 DeepSeek（推荐，便宜好用）

1. 打开浏览器，访问 **https://platform.deepseek.com**
2. 注册账号（需要手机号）
3. 登录后，点击左侧「**API Keys**」
4. 点击「**创建 API Key**」，复制生成的 Key（以 `sk-` 开头）
5. 在项目根目录找到 `.env.example` 文件，复制一份，改名为 `.env.local`
6. 打开 `.env.local`，找到这一行：

```
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

7. 把 `your_deepseek_api_key_here` 替换成你刚才复制的 Key：

```
DEEPSEEK_API_KEY=sk-在这里粘贴你自己的密钥
```

8. 保存文件，重启项目（终端里按 `Ctrl+C` 停止，再输入 `npm run dev`）

### 方式 B：用 OpenAI（GPT）

1. 访问 **https://platform.openai.com** 注册账号
2. 创建 API Key
3. 在 `.env.local` 中填入：

```
OPENAI_API_KEY=sk-your-key-here
```

4. 保存，重启项目

### 方式 C：用其他兼容 API

如果你有其他 OpenAI 兼容的 API（比如 Azure OpenAI、本地 Ollama 等），在 `.env.local` 中配置：

```
OPENAI_API_KEY=your-key
OPENAI_BASE_URL=https://your-api-endpoint.com/v1
```

### 怎么确认 AI 已经生效？

1. 打开项目首页
2. 输入一个问题开始解读
3. 如果解读内容比模板更自然、更贴合你的问题 → AI 生效了
4. 如果解读比较模板化 → 可能 Key 没填对，检查 `.env.local`

## 6. 怎么使用

### 首页：三种进入方式

| 方式 | 适合场景 | 说明 |
|------|---------|------|
| **今日一牌** | 没有具体问题，随便看看 | 抽一张牌，看看今天有什么值得被看见 |
| **问题解读**（推荐） | 有一个具体问题 | 系统先帮你澄清问题，再推荐牌阵 |
| **深度牌阵** | 问题比较复杂，反复出现 | 用多张牌，慢慢看见问题的层次 |

### 解读流程

1. **输入问题** — 写下你此刻在想什么（不需要完整，可以模糊）
2. **系统复述** — 系统会帮你重新描述问题，你可以接受、修改或跳过
3. **选择牌阵** — 系统推荐合适的牌阵，你也可以自己选
4. **抽牌翻牌** — 看牌面动画
5. **探索牌面** — 点击牌面上的亮点符号，查看解释
6. **分步阅读** — 按位置查看每张牌的解读
7. **写下感受** — 可以写一句话，保存为快照
8. **回看笔记** — 以后随时可以在「笔记」页面回看

### 档案馆

- 查看 78 张牌的完整资料
- 点击牌面可以查看符号解释
- 正位 / 逆位含义

### 科普导览

- 了解塔罗牌的基础知识
- 了解不同牌阵的含义
- 了解三种进入方式的区别

### 笔记

- 查看所有保存的解读快照
- 可以继续补写感受
- 可以固定重要的解读
- 所有数据只存在你的电脑上，不会上传

## 7. 常见问题

### Q: `npm install` 报错怎么办？

**A:** 试试以下方法：

```bash
# 清除缓存重试
rm -rf node_modules package-lock.json
npm install
```

如果还是不行，检查 Node.js 版本：
```bash
node --version
```
需要 18 或更高版本。如果版本太低，去 https://nodejs.org 重新下载安装。

### Q: 端口 3000 被占用了怎么办？

**A:** 启动时会自动换端口（比如 3001、3004）。看终端里显示的 `Local:` 地址就行。

或者手动指定端口：
```bash
npm run dev -- -p 3001
```

然后访问 http://localhost:3001

### Q: 打开页面是空白的怎么办？

**A:**
1. 等几秒钟，页面可能还在加载
2. 按 `F5` 刷新
3. 检查终端有没有红色错误信息
4. 清除浏览器缓存：按 `Ctrl+Shift+Delete`，清除缓存后刷新

### Q: 牌面图片加载不出来怎么办？

**A:**
1. 检查网络连接
2. 刷新页面
3. 如果还是不行，在终端运行：
```bash
npm run cards:download
npm run cards:wire
```

### Q: 怎么停止项目？

**A:** 在终端里按 `Ctrl + C`（Mac 也是 `Ctrl + C`，不是 `Cmd + C`）

### Q: 怎么重新启动？

**A:**
```bash
cd tarot-reflector
npm run dev
```

### Q: 怎么更新到最新版本？

**A:**
```bash
cd tarot-reflector
git pull
npm install
npm run dev
```

### Q: 数据会丢失吗？

**A:** 笔记和解读历史保存在浏览器的 localStorage 里：
- 清除浏览器缓存会丢失数据
- 换浏览器不会同步
- 不会上传到任何服务器

### Q: 可以部署到线上让别人也能用吗？

**A:** 可以。最简单的方式是部署到 Vercel：

```bash
npm install -g vercel
vercel login
vercel
```

或者用 CodeBuddy，告诉它"帮我部署到 Vercel"。

### Q: 在哪里申请 DeepSeek API Key？

**A:**
1. 访问 https://platform.deepseek.com
2. 注册账号（需要手机号）
3. 登录后点「API Keys」→「创建」
4. 复制 Key，粘贴到 `.env.local`

新用户通常有免费额度，够用很久。

### Q: AI 解读和本地模板有什么区别？

**A:**

| | 本地模板 | AI 解读 |
|---|---------|---------|
| **需要 API Key** | ❌ 不需要 | ✅ 需要 |
| **解读质量** | 通用牌义，比较模板化 | 更贴合你的具体问题 |
| **语言风格** | 固定模板 | 更自然，像朋友在说话 |
| **多牌阵分析** | 基础 | 更深入的关系分析 |
| **速度** | 瞬间 | 需要几秒（AI 生成中） |

**建议：** 先用本地模板体验，觉得好用了再接入 AI。
