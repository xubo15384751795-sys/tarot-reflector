# 阈牌 · 部署与使用指南（零基础版）

> 这份文档写给**不会写代码、也没用过 GitHub** 的人。
> 全程跟着点鼠标、填表格就行，遇到看不懂的英文按文档里的中文对照来。
>
> 读完你能做到两件事之一：
> 1. 把阈牌**发布成一个网址**，自己和朋友都能用（推荐）；
> 2. 或者只在**自己的电脑上**先跑起来试试。

---

## 0. 开始前，先理解两件事

**第一件：阈牌是一个网站应用。**
它不是手机 App，不需要在应用商店下载。它最终是一个网址（比如 `https://你的名字.vercel.app`），用浏览器打开就能用。

**第二件：AI 解读是「可选项」。**
阈牌有两层体验：

| | 不填 API Key（默认） | 填了 API Key |
|---|---|---|
| 今日一牌 / 抽牌 / 翻牌 | ✅ 正常 | ✅ 正常 |
| 牌面符号、档案馆、笔记 | ✅ 正常 | ✅ 正常 |
| **AI 写的个性化解读** | ⚠️ 用内置的本地牌义兜底 | ✅ 由 AI 针对你的问题生成 |

所以：**你可以先不填 Key 把它跑起来**，玩顺了再回头开通 AI。下面会教你怎么开通。

## 路线总览

- **路线 A —— 发布成网址（推荐）**：用一个叫 **Vercel** 的免费平台。不用装任何软件，全程网页操作。👉 看 [第 1 节](#路线-a发布成一个网址vercel推荐)

如果你拿不定主意，**选路线 A**。它更简单，而且做出来是一个能分享的真网址。

## 路线 A：发布成一个网址（Vercel，推荐）

### 你需要的账号

1. 一个 **GitHub** 账号（项目已经放在这里：`github.com/xubo15384751795-sys/tarot-reflector`）。
   如果项目就是你自己的，你应该已经有这个账号了。
2. 一个 **Vercel** 账号（下一步直接用 GitHub 登录，不用单独注册）。

### 第 1 步：登录 Vercel

1. 打开浏览器，访问 **https://vercel.com** 。
2. 点右上角 **Sign Up**（注册）或 **Log In**（登录）。
3. 选择 **Continue with GitHub**（用 GitHub 继续），用你的 GitHub 账号授权登录。
4. 第一次会问你是个人使用还是团队，选 **Hobby（个人 / 免费）** 即可。

### 第 2 步：把项目导入 Vercel

1. 登录后，点 **Add New…**（新增）→ **Project**（项目）。
2. Vercel 会列出你 GitHub 上的仓库。找到 **tarot-reflector**，点它右边的 **Import**（导入）。
   - 如果列表里没有，点 **Adjust GitHub App Permissions**（调整 GitHub 授权），勾上这个仓库再回来。
3. 进入配置页。**绝大多数设置保持默认即可**：
   - Framework Preset（框架）：会自动识别为 **Next.js**，不用改。
   - Build / Output 设置：**不用动**。

### 第 3 步（可选）：填 API Key，开启 AI 解读

如果你**现在就想要 AI 解读**，在导入页面往下找到 **Environment Variables（环境变量）**，按下面填。
（不想现在弄也行，先跳过，以后随时能加，见 [第 2 节](#第-2-节怎么开通-ai-解读拿-deepseek-api-key)。）

逐行添加（左边是 **Name 名字**，右边是 **Value 值**）：

| Name（名字） | Value（值） |
|---|---|
| `AI_PROVIDER` | `deepseek` |
| `DEEPSEEK_API_KEY` | 你的 DeepSeek 密钥（见第 2 节，形如 `sk-xxxxxxxx`） |

> 每填一行点一下 **Add**。这些值只存在 Vercel 后台，不会出现在网页上、也不会泄露给访问者。

### 第 4 步：部署

1. 点最下面的 **Deploy（部署）**。
2. 等 1～3 分钟，看到一串绿色对勾和彩带动画，就成功了。
3. 点 **Visit（访问）** 或页面上的预览图，就能打开你的阈牌网址了，形如：
   `https://tarot-reflector-xxxx.vercel.app`
4. 这个网址可以直接发给任何人，他们用浏览器就能打开。

### 第 5 步：以后怎么更新

只要项目在 GitHub 上有新改动（你或协作者推送了代码），**Vercel 会自动重新部署**，你什么都不用做，过几分钟刷新网址就是最新版。

> 想绑定自己的域名（比如 `tarot.你的域名.com`）？在 Vercel 项目里点 **Settings → Domains**，按提示添加即可。没有域名也完全不影响使用。

## 第 2 节：怎么开通 AI 解读（拿 DeepSeek API Key）

阈牌默认用 **DeepSeek**（一个国内可直接注册、价格很低的 AI 服务）来写解读。拿 Key 的流程：

1. 打开 **https://platform.deepseek.com** ，注册 / 登录（支持手机号）。
2. 登录后，在左侧菜单找到 **充值 / Billing**，充一点点钱即可（解读一次只花几厘到几分钱，充 ¥10 能用很久）。
3. 在左侧找到 **API Keys（密钥）** → 点 **创建 / Create new key**。
4. 给它起个名字（随便填，比如 `tarot`），创建后会出现一串 **`sk-` 开头的密钥**。
   ⚠️ **这串密钥只显示一次，立刻复制保存好。** 关掉就看不到了，丢了只能重新建一个。
5. 把这串密钥填到 Vercel 的环境变量里（路线 A 的第 3 步），或填到本地的 `.env.local`（路线 B 的第 4 步）。

**已经部署好了才想加 Key？** 去 Vercel：
**项目 → Settings（设置）→ Environment Variables（环境变量）** 添加上面两行，然后到 **Deployments（部署记录）** 点最新一条右侧的 **⋯ → Redeploy（重新部署）**，让新 Key 生效。

> 不想用 DeepSeek，想用 OpenAI 也可以：把 `AI_PROVIDER` 填成 `openai`，再加 `OPENAI_API_KEY`、`OPENAI_MODEL`（如 `gpt-4o-mini`）两个变量即可。

## 路线 B：在自己电脑上运行

适合：你想先在本机试一试，不打算让别人访问。
（关掉终端窗口，网站就停了；想让别人也能用，请走路线 A。）

### 第 1 步：安装 Node.js（只需一次）

阈牌需要一个叫 **Node.js** 的运行环境。

1. 打开 **https://nodejs.org** 。
2. 下载左边那个 **LTS（长期支持版）**，版本号 **20 或更高**。
3. 双击下载好的安装包，一路 **下一步 / Next / 同意**，装完即可。
4. 验证是否装好：
   - **Windows**：按 `Win` 键搜 “**命令提示符**” 或 “**PowerShell**” 打开它。
   - **Mac**：按 `Command + 空格` 搜 “**终端 / Terminal**” 打开它。
   - 在里面输入下面这行，按回车，能看到一个版本号就说明装好了：
     ```
     node -v
     ```

### 第 2 步：把项目下载到电脑

**最简单的办法（不用 GitHub 知识）：**

1. 打开项目页面：`https://github.com/xubo15384751795-sys/tarot-reflector`
2. 点绿色的 **Code（代码）** 按钮 → **Download ZIP（下载压缩包）**。
3. 把下载的 zip **解压**，会得到一个 `tarot-reflector` 文件夹。记住它在哪（比如桌面）。

### 第 3 步：在项目文件夹里打开终端

- **Windows**：打开那个文件夹，在地址栏输入 `cmd` 按回车，会在这个文件夹打开命令窗口。
- **Mac**：打开“终端”，输入 `cd ` （cd 后面有个空格），然后把 `tarot-reflector` 文件夹**拖进终端窗口**，按回车。

> 怎么确认进对文件夹了？输入 `ls`（Mac）或 `dir`（Windows）回车，应该能看到 `package.json`、`src` 这些名字。

### 第 4 步（可选）：开启 AI 解读

如果想要 AI 解读，在 `tarot-reflector` 文件夹里**新建一个文本文件，命名为 `.env.local`**（注意开头有个点、没有 `.txt` 后缀），里面写两行：

```
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你在第2节拿到的sk-开头的密钥
```

保存。不想现在弄就跳过这步，今日一牌依然能用。

### 第 5 步：安装依赖 + 启动

在终端里**依次**输入这两行（每行回车后等它跑完）：

```
npm install
```
（第一次会下载一堆东西，可能要等几分钟，属于正常。）

```
npm run dev
```

看到类似 `Local: http://localhost:3000` 的字样，就启动成功了。

### 第 6 步：打开网站

打开浏览器，访问：

```
http://localhost:3000
```

阈牌就出现了。

> **想关掉？** 回到终端窗口，按 `Ctrl + C`。下次想再开，重复第 3 步和 `npm run dev` 即可（`npm install` 只有第一次需要）。

## 第 3 节：怎么使用阈牌

打开网站后：

### 三种进入方式（首页）

- **今日一牌** —— 没有具体问题时用，抽一张牌看看今天值得被轻轻看见的是什么。
- **问题解读**（推荐入口）—— 带一个具体问题进来，系统会先帮你把问题说清楚，再推荐合适的牌阵。
- **深度牌阵** —— 适合反复出现、暂时说不清的问题，用多张牌慢慢看层次。

### 活牌面（最特别的地方）

抽出牌后，**牌面是“活”的**：牌面图上有几个**金色小圆点**。
**用鼠标点 / 手指轻触这些金点**，旁边就会浮现这个符号代表什么含义。
第一次进入时，顶部会有一条提示带你认识这个交互——这就是阈牌和普通“抽牌出文字”工具最大的不同。

### 档案馆 `/archive`

在左侧菜单点 **档案**，可以浏览全套 78 张牌：

- 上方按 **大阿尔卡那 / 四种花色（权杖·圣杯·宝剑·星币）** 分组。
- 点任意一张牌，会弹出**大图 + 活牌面**，同样可以点金点看符号。
- 弹窗里还有 **正位 / 逆位 / 牌面符号 / 牌阵含义** 四个标签页。

### 牌面笔记 `/notes`

一次解读结束后，可以写下一句话感受，并把这次的**牌面、问题、解读、笔记一起固定成快照**，之后按月回看。

### 切换主题

右上角有个**月白 / 夜间**的小开关，可以在浅色和深色之间切换，按你舒服的来。

## 第 4 节：常见问题（FAQ）

**Q：必须花钱吗？**
- Vercel 个人版**免费**，足够个人使用。
- 只有 AI 解读需要 DeepSeek 充值，而且**很便宜**（解读一次几厘到几分钱）。不充钱也能用今日一牌等全部其他功能。

**Q：网站打开了，但 AI 解读不出来 / 一直转圈后用了模板？**
- 多半是没填 Key，或 Key 填错 / DeepSeek 余额为 0。
- 检查：Vercel 的环境变量里 `DEEPSEEK_API_KEY` 是否填对、有没有多余空格；DeepSeek 后台是否还有余额。
- 改完记得 **Redeploy（重新部署）** 才会生效。
- 注意：阈牌设计上**即使 AI 失败也不会报错**，它会安静地用本地牌义兜底，让你先看牌面——所以“出了内容但感觉比较模板化”，通常就是 Key 还没生效。

**Q：本地运行时提示 `localhost:3000` 打不开 / 端口被占用？**
- 说明 3000 端口被别的程序占了。终端里改用别的端口启动：
  ```
  npm run dev -- -p 3100
  ```
  然后访问 `http://localhost:3100`。

**Q：本地 `npm install` 报错？**
- 先确认 Node.js 是 **20 或更高**（`node -v` 看版本）。版本太低就回 nodejs.org 重新装 LTS。
- 网络问题导致下载失败的话，换个网络环境重试一次 `npm install`。

**Q：Vercel 部署失败（红色 ✕）？**
- 点开那次部署看 **Build Logs（构建日志）**，最后几行红字是原因。
- 最常见是**环境变量名字打错**（比如把 `DEEPSEEK_API_KEY` 写成别的）。改对后重新部署即可。

**Q：我的 API Key 会泄露吗？**
- 不会。Key 只存在 Vercel 后台或你本机的 `.env.local` 里，**不会出现在网页源码、也不会发给访问者**。但仍请不要把 Key 截图发给别人。

## 一句话总结

> 想要一个能分享的网址 → **路线 A（Vercel）**，3 步点完。
> 只想先在自己电脑上试 → **路线 B**，装 Node、下载项目、`npm install` + `npm run dev`。
> 想要 AI 解读 → 去 DeepSeek 拿一个 `sk-` 开头的 Key 填进去。其余功能不填 Key 也能用。
