# Motion Direction

## 1. 核心感受

页面打开时，你站在一间几乎没开灯的档案室里，面前是一张旧书桌。光从侧上方落下来，范围很窄，像有人把台灯压低了一格。书页边缘比中心更亮，纸纤维在光里隐约可见，偶尔有一粒灰尘穿过光束，很慢，不是装饰，是空气本身在动。

摄影机没有切镜头，只是向前推：先是房间，再是桌面，再是摊开的书，最后停在纸上的牌。牌没有「弹出来」，它一直在那里，是你走近了，才看清纹理和阴影。

文字像档案柜上的标签，或手稿边注：位置稳定，语气克制，不抢着说明。它随空间微微位移，是因为镜头在动，不是因为标题要表演。

滚动时，身体的感觉是「靠近」而不是「翻页」。停下来时，画面应该还能被当作一张完整的静物摄影——暗、暖、浅、有呼吸的空间，而不是动画播完后的空壳。

---

## 2. 动效原则

1. **Motion is camera first, component second.** 先决定镜头如何移动，再决定物体在镜头中的位置；禁止为每个组件单独编排入场秀。

2. **主视觉是空间锚点。** 书、牌、桌面构成不可拆散的构图中心；动效服务于「让你走近这个锚点」，不服务于「展示更多 UI 块」。

3. **文字少动，图像和光线承担主要运动。** 标题与说明以 opacity 或极微位移配合镜头即可；读者用眼睛读字，不用追字。

4. **所有运动都应该解释空间、注意力或状态。** 每一帧变化都要能回答：更远还是更近？更亮还是更暗？注意力落在哪里？当前是浏览、停读还是离开？

5. **动画宁可少，不可多。** 一个主轴胜过六个点缀；留白和停格是叙事的一部分。

6. **如果一个动画没有叙事理由，就删掉。** 不能回答「为何此时动」的效果，一律不保留。

7. **hover 不要像按钮模板，要像光线变化。** 靠近时边框略暖、阴影略深、烛光略亮即可；不要位移、放大、弹跳。

8. **reduced motion 下页面仍然成立。** 关闭运动偏好时，呈现一帧构图完整、信息可读的静物画面，而非「残缺的动画版」。

## 3. 禁止清单

1. generic fade-up（元素从下方淡入上浮）
2. random stagger（无节奏的依次出现）
3. bounce（弹性回弹）
4. springy SaaS motion（过冲、振荡的弹簧感）
5. excessive glow（大面积外发光、霓虹感）
6. rotating cards（牌面无叙事地旋转）
7. every card animating independently（每张牌各自一套入场）
8. large scale transform（无镜头理由的大幅缩放）
9. moving more than 24px without camera reason（非摄影机推动的明显位移）
10. animating width / height / top / left（触发布局重排的属性动画）
11. infinite decorative animation（无限循环的装饰动效）
12. overusing blur（用模糊掩盖切换或制造廉价景深）
13. hover scale above 1.02（悬停放大超过 2%）
14. all sections sharing same animation（全站段落共用同一套 fade-up）
15. text and image moving at same speed（文字与图像同速平移，缺乏景深层次）
16. 粒子爆炸、 confetti、转盘、抽卡爆闪
17. 倒计时、恐吓式 CTA 动效
18. 同时混用 GSAP 与 Framer 控制同一 DOM 的 transform / opacity
19. 用 setTimeout 串联复杂时间轴
20. 按钮扫光、金属 sheen 作为默认 hover 语言
21. 三栏文档式布局配合逐块 slide-in
22. emoji 或高饱和装饰作为动效触发点

## 4. 参考方向

以下仅为气质抽象，**不复制任何现有网站**：

- **cinematic archive** — 镜头语言优先的档案空间，像记录片开场而非产品宣传片
- **quiet museum** — 低音量、低对比动效，观众自行走近展品
- **old book under weak light** — 弱光下的旧书：纸边亮、纸心暗、色温偏暖
- **dust in a narrow beam of light** — 窄光束里的微尘，极慢、极少、可忽略
- **slow camera push** — 单一推轨，无跳切
- **shallow depth** — 浅景深：前景清晰、背景柔化，靠遮罩与虚实而非乱 blur
- **restrained editorial typography** — 编辑排版：字是场景的一部分，不是横幅广告

## 5. 质量判断标准

### 成功

- 即使关闭动画，静态画面也像一张完成度高的视觉海报：构图、明暗、材质、留白均成立。
- 滚动时感觉是摄影机在靠近空间，而不是元素在表演各自的小节目。
- 动画很少，但页面有空气感——暗处有暗、光处有光、停住时仍能「待一会儿」。
- 文字、图像、光线、颗粒存在层次：字稳、物实、光弱、尘稀。
- reduced motion 下信息完整、情绪不塌，无需依赖运动才能理解场景。
- 动效只使用 transform 与 opacity（及烛光等层的 opacity），滚动跟手、无布局抖动。

### 失败

- 像 PPT：一页一页「出现」，缺乏连续空间。
- 像模板站：玻璃卡片、渐变底、统一 fade-up，换文案即可复用到任意 SaaS。
- 所有卡片一起淡入，或 stagger 像抽奖揭晓。
- 动效词汇只有 fade、scale、slide，没有镜头、光线、景深。
- hover 像普通 UI kit：放大、阴影暴涨、弹性反馈。
- 为了「有动效」而加粒子、扫光、循环呼吸，叙事上无依据。
- 文字与图像同速、同向乱动，看不出主次与远近。
- 关掉动画后只剩零散组件，不像一个完整的「房间」。
